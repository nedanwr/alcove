# @alcove/db

Drizzle ORM schema and database factory for Alcove, backed by Cloudflare D1 (SQLite).

```ts
import { createDb, mailboxes } from "@alcove/db";

const db = createDb(env.DB);
```

The schema in `src/schema` is plain `drizzle-orm/sqlite-core`; only `src/d1.ts` depends on Cloudflare.

## Migrations

Migrations are generated by Drizzle Kit into `migrations/` and applied by Wrangler, which reads the same directory through `migrations_dir` in `apps/web/wrangler.jsonc`.

```sh
# After changing the schema
pnpm --filter @alcove/db db:generate --name <change>

# Apply to the local dev database / to the deployed database
pnpm --filter @alcove/web db:migrate:local
pnpm --filter @alcove/web db:migrate:remote
```

Do not edit generated migrations or `migrations/meta` by hand.
