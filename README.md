# Alcove

Alcove is an open-source, modular cloud workspace designed to run on [Cloudflare Workers](https://workers.cloudflare.com/).

Starting with email and expanding into file storage, Alcove aims to provide a unified, self-hostable alternative to traditional cloud productivity platforms—without the complexity or infrastructure overhead.

> [!WARNING] > **Status: Experimental.** Not recommended for production use.
